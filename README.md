Tujuan: menyimpan dan mengelola kode proyek secara terpusat.

informasi Kegiatan Workshop

Workshop bertema “Building with AI, Managing Change with GitHub” membahas pemanfaatan AI dalam pembuatan aplikasi serta penggunaan Git dan GitHub untuk mengelola perubahan kode program.
Kegiatan dipandu oleh Nugi Farhan selaku Senior Product Designer. Peserta mempelajari teknik Prompt Engineering, dasar-dasar Git dan GitHub, serta praktik membuat aplikasi sederhana bernama Student Task Planner dengan bantuan AI.
Melalui kegiatan ini, peserta memperoleh pengetahuan dan pengalaman dalam menggunakan AI serta GitHub untuk mendukung proses pengembangan aplikasi.

Rangkuman Materi Workshop
Materi workshop Building with AI, Managing Change with GitHub membahas dua topik utama:
1. Prompt Engineering dan AI Mempelajari cara membuat instruksi (prompt) yang jelas, spesifik, dan terstruktur agar AI dapat memberikan hasil yang sesuai kebutuhan. Struktur prompt terdiri dari Role, Task, Context, dan Format.
2. Pengenalan Git dan GitHub Mempelajari perbedaan Git sebagai alat untuk mencatat perubahan kode dan GitHub sebagai platform penyimpanan repository secara online serta kolaborasi.
3. Dasar-Dasar Git Mengenal repository, commit, branch, pull request, staging area, dan working directory.
4. Perintah Dasar Git Mempelajari perintah seperti `git init`, `git add`, `git commit`, `git push`, `git pull`, dan `git clone`.
5. Praktik Pembuatan Aplikasi Peserta mempraktikkan pembuatan aplikasi sederhana bernama Student Task Planner menggunakan bantuan AI, kemudian mengunggah dan mengelola proyek melalui GitHub.
Kesimpulan: Workshop ini memberikan pemahaman dasar tentang pemanfaatan AI untuk membuat aplikasi serta penggunaan Git dan GitHub untuk menyimpan, mengelola, dan mengembangkan proyek pemrograman.

Poin-Poin Penting dan Pengetahuan Selama Workshop
* Memahami cara membuat prompt AI yang jelas dan spesifik.
* Mengetahui struktur prompt yang baik, yaitu Role, Task, Context, dan Format.
* Memahami perbedaan Git dan GitHub.
* Mengetahui fungsi repository, commit, branch, dan pull request.
* Mempelajari perintah dasar Git untuk mengelola perubahan kode.
* Mengetahui cara mengunggah dan menyimpan proyek ke GitHub.
* Mendapatkan pengalaman membuat aplikasi sederhana menggunakan bantuan AI.
